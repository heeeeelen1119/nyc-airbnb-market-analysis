# Data placement

Place these unmodified files in `data/raw/` before running the pipeline:

- `airbnb_price.csv` — listing identifier, price text, and combined borough/neighborhood
- `airbnb_room_type.xlsx` — listing identifier, description, and room type
- `airbnb_last_review.tsv` — listing identifier, host name, and last-review date

The raw inputs are excluded from version control. `data/processed/` is generated by `python src/clean.py`; its row-level CSV and Parquet outputs are also excluded.
